## 로컬 환경 세팅 방법

터미널을 열어 아래 단계별로 명령어를 입력합니다.

<Steps>
    <Step>
    
    ### Homebrew 설치
    터미널에서 패키지를 다운받을 수 있도록 Homebrew를 설치합니다.

    ```bash
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    ```

    ```bash
    brew --version
    ```
    `brew --version` 명령어 입력 후 설치된 버전이 나오면 다음 단계로 이동

    </Step>
    <Step>

    ### Git 설치
    다운받은 Homebrew로 git을 설치합니다.

    ```bash
    brew install git
    ```

    ```bash
    git --version
    ```
    위와 동일하게 설치된 버전 확인 후 다음 단계로 이동

    </Step>
    <Step>
    ### Node.js 설치
    개발 프로그램을 설치합니다.
    아래 순서대로 명령어 입력하여 노드 버전 매니저 설치

    ```bash
    brew install nvm
    ```
    {/* zsh 설정 */}

    ```bash
    mkdir ~/.nvm
    ```
    ```bash
    echo 'export NVM_DIR="$HOME/.nvm"' >> ~/.zshrc
    ```
    ```bash
    echo '[ -s "/opt/homebrew/opt/nvm/nvm.sh" ] && \. "/opt/homebrew/opt/nvm/nvm.sh"' >> ~/.zshrc
    ```
    ```bash
    source ~/.zshrc
    ```

    {/* Node LTS 설치 */}

    ```bash
    nvm install --lts
    ```
    ```bash
    nvm use --lts
    ```

    ```bash
    node -v
    ```
    ```bash
    npm -v
    ```

    설치된 버전 확인 후 다음 단계로 이동
    </Step>
    <Step>
    ### bun 설치
    프로젝트 패키지 설치 프로그램을 다운받습니다.

    ```bash
    curl -fsSL https://bun.sh/install | bash
    ```

    ```bash
    bun -v
    ```
    설치 버전 확인 후 다믕 단계로 이동
    </Step>
    <Step>
    ### 프로젝트 코드 내려받기
    문서 작업을 위해 폴더를 하나 만든 뒤,
    해당 폴더를 VS Code 에서 엽니다.

    1. VS Code를 실행합니다
    2. New Window 버튼을 클릭해서 생성한 폴더를 선택합니다.
    3. 상단 메뉴에서 Terminal → New Terminal을 선택합니다.
    4. 아래 명령어를 입력하여 프로젝트 코드를 다운받습니다.
    ```bash
    git clone https://github.com/stunitas-tech/st-design.git
    ```
    5. 내려받은 `st-design` 폴더를 확인합니다.


    </Step>

    <Step>
    ### 프로젝트 실행

    1. 다시 VS Code를 실행합니다.
    2. New Window 버튼을 클릭해서 내려받은 `st-design` 을 선택합니다.
    3. 상단 메뉴에서 Terminal → New Terminal을 선택합니다.
    4. 아래 명령어를 입력하여 프로젝트를 실행 후 이 링크로 접속합니다. (http://localhost:3000/docs)
    ```bash
    bun run docs:dev
    ```
    </Step>

</Steps>
