## Overview

타이포그래피는 명확하고 쉽게 전달하기 위한 핵심 디자인 요소입니다. 재사용 가능한 타이포그래피 토큰을 통해 다양한 텍스트 스타일을 체계적으로 관리할 수 있으며,
이를 바탕으로 일관된 시각적 계층 구조와 가독성을 유지할 수 있습니다.
![typograhpy](/images/docs/foundation/typography/img1.png)

## 타이포그래피 토큰

### 폰트 사이즈 토큰

폰트 사이즈는 접근성과 확장성을 위해 상대 단위인 rem(1rem=10px)을 사용합니다.
피그마에서는 텍스트 스타일을 사용하고, 코드에서는 타이포그래피 토큰을 사용합니다.

{/* 임시 데이터.텍스트 토큰 값으로 노출 필요 */}

| 이름                | weight | size | line-height | letter-spacing |
| ------------------- | ------ | ---- | ----------- | -------------- |
| font-Display.700.44 | 700    | 44   | 150%        | 0%             |
| font-Display.700.40 | 700    | 40   | 150%        | 0%             |
| font-Heading.700.24 | 700    | 24   | 145%        | -1%            |

### 폰트 두께 토큰

명확한 시각적 대비와 계층 구조를 위해 4가지 폰트 두께 토큰을 정의합니다.

| 이름                 | 값  |
| -------------------- | --- |
| font-weight.Regular  | 400 |
| font-weight.medium   | 500 |
| font-weight.semibold | 600 |
| font-weight.bold     | 700 |
