# Color Token


대부분의 디자인 제품 경험에서는 디자인 토큰을 통해 색상을 적용합니다.
이는 특정 색상값을 직접 선택하기 보다는 미리 정의된 디자인 토큰을 선택하여 색상을 사용하는 방식을 의미합니다.
디자인 토큰을 사용하여 일관성을 유지하고 접근성 대응 및 다양한 상황에 유연하게 대응할 수 있습니다.


![image.png](/images/docs/foundation/color/colors/image-0.png)


# Saturated colors


선명한 색상은 사용자에게 의미있는 인상을 주고, 중요한 화면 요소를 강조하거나 유사한 색상 UI와 연관성을 만들 수 있습니다.


![image.png](/images/docs/foundation/color/colors/image-1.png)


# Neutral colors


중립 색상은 주로 배경이나 텍스트, 도형 등 다양한 UI 요소와 상태에 사용됩니다. 이 색상들은 일반적으로 특정한 의미를 가지지 않지만 안정성과 균형을 제공합니다.


![image.png](/images/docs/foundation/color/colors/image-2.png)


# Alpha colors


알파 색상은 투명도의 정도가 다른 색상을 의미합니다.이러한 투명 효과는 UI가 다양한 배경 색상이나 레이어 위에 자연스럽게 어우러지도록 도와줍니다. 
투명도를 활용하면 시각적 깊이와 계층 구조를 표현할 수 있으며, 인터페이스의 유연성과 일관성을 높일 수 있습니다.


![image.png](/images/docs/foundation/color/colors/image-3.png)
