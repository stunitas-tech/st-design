## 디자인 토큰 가이드

대부분의 디자인 제품 경험에서는 디자인 토큰을 적용합니다. 이는 특정 사이즈 및 색상값을
직접 선택하기 보다는 미리 정의된 값을 선택하여 사용하는 방식을 의미합니다. 이를 통해 브랜드 일관성을 유지하고, 접근성 대응 및 다양한 상황에 유연하게 대응할 수 있습니다.

![designtoken](/images/docs/foundation/designtoken/img1.png)

모든 토큰은[Category, Property, Type, State, Size]로 구성되며 이러한 명명 규칙은 토큰의 용도를 직관적으로 파악하고, 일관된 방식으로 적용하는 데 도움을 줍니다.

| 항목     | 의미                        | 일부 예시                                              |
| -------- | --------------------------- | ------------------------------------------------------ |
| Category | 전체 토큰 대분류            | Diemnsion, Semantic Color, Pallete, Effect, Typography |
| Property | 적용되는 대상,속성          | background, text, icon, stroke, spacing, radius        |
| Variants | 컴포넌트나 용도에 따른 변형 | backdrop, cover                                        |
| Type     | 스타일의 유형               | default, weak, subtle, tint, contrast, inverted, mute  |
| State    | UI의 상태                   | nomal, hovered, focused, pressed, disabled             |
| Scale    | UI의 크기                   | Numbers                                                |

## 색상 토큰

색상 토큰은 각 색상에 의미 있는 이름을 붙여 관리하는 방식으로, 제품 전반에서 일관되게 색을 사용할 수 있게 해줍니다.

![colortoken](/images/docs/foundation/designtoken/img2.png)

색상에 관련된 추가 지침은 Color System을 참고해주세요.

## 타이포그래피 토큰

타이포그래피 토큰은 디자인 시스템에서 텍스트의 스타일 속성들을 이름으로 정의한 단위입니다.
폰트 크기, 굵기, 줄 간격, 자간 등 텍스트 구성 요소들을 의미 있는 이름으로 정리하여, 일관된 텍스트 표현과 유지 관리를 가능하게 합니다.

![typographytoken](/images/docs/foundation/designtoken/img3.png)

글자에 관련된 추가 지침은 Typography을 참고해주세요.
