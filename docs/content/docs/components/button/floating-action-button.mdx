## Properties

### Size

![image.png](/images/docs/components/button/floating-action-button/image-1.png)

플로팅 액션 버튼은 화면의 중요도와 디바이스 환경의 터치 영역을 고려하여 두 가지 사이즈를 제공합니다.

| Device  | size  |
| ------- | ----- |
| &gt;768 | Small |
| 767&lt; | Large |

### Variant

플로팅 액션 버튼의 시각적 스타일 변주를 제공합니다.

![image.png](/images/docs/components/button/floating-action-button/image-2.png)

- **Primary** : 강조 색상을 사용하여 가장 주요한 액션에 적용합니다.
- **Assistive** : 무채색을 사용하여 배경과의 대비를 낮추고 시각적 피로도를 줄일 때 적용합니다.

### State

![image.png](/images/docs/components/button/floating-action-button/image-3.png)

사용자 상호작용 상태를 나타냅니다. `:nomal` `:hovered` `:focused` `:pressed` 를 활용하여 각 상태에 맞는 시각적 피드백을 제공합니다.

### Extended Property

Extended Property를 켜면 텍스트를 표시할 수 있습니다. 이를 통해 기능을 텍스트로 명확히 표현하여 직관성을 높일 수 있습니다.

![image.png](/images/docs/components/button/floating-action-button/image-4.png)

## Guidelines

### Hierarchy

플로팅 액션 버튼은 화면 내 다른 콘텐츠보다 항상 시각적으로 우위에 있어야 합니다. 페이지 스크롤 시에도 고정된 위치를 유지해야 합니다

![image.png](/images/docs/components/button/floating-action-button/image-5.png)

| **요소**               | **시각적 중요도** | **Z-Index**            | **배치 기준**                    |
| ---------------------- | ----------------- | ---------------------- | -------------------------------- |
| Floating Action Button | 가장 높음         | 최상단 (예: 1000 이상) | 다른 컴포넌트의 위에 오버레이 됨 |
| Bottom Navigation      | 높음              | 중간                   | FAB 아래, 일반 콘텐츠 위         |
| Page Content           | 기본              | 기본                   | 화면 가장 아래 레이어            |
| Scrim/Dimmer           | 높음              | FAB 위                 | 상황에 따라 변경                 |

### Floating Action Button의 위치

화면 우측 하단 여백을 유지하며 고정된(Fixed) 위치에 배치합니다.

![image.png](/images/docs/components/button/floating-action-button/image-6.png)

### Scroll 동작 방식

Anchor 기능을 제공하는 버튼의 경우 위로 스크롤 시에는 숨김 처리 됩니다.

![image.png](/images/docs/components/button/floating-action-button/image-7.png)

## Usage

### Label Usage

Extended 타입의 플로팅 액션 버튼에 적용되는 너비 제한입니다.

![image.png](/images/docs/components/button/floating-action-button/image-8.png)

<Callout title="Don’t  " type="error">

텍스트 길이가 가변적일 경우를 대비하여 최대 너비(Max-width)를 지정하여 디자인이 깨지지 않도록 합니다. 텍스트가 최대 너비를 초과할 경우 미노출 처리됩니다.

</Callout>

## Specification

### **base**

| **상태** | **슬롯**  | **속성**        | **값**                           |
| -------- | --------- | --------------- | -------------------------------- |
| Default  | Container | border-radius   | 999px(max)                       |
| Default  | Container | box-shadow      | 2px 4px 10px rgba(0, 0, 0, 0.06) |
| Default  | Container | display         | flex                             |
| Default  | Container | align-items     | center                           |
| Default  | Container | justify-content | center                           |
| Default  | Container | position        | fixed                            |

### **Variant**

버튼의 시각적 형태를 결정하는 스타일 속성으로, HTML 클래스(예: `.btn-solid`, `.btn-outline`)를 통해 제어합니다.

| **상태** | **슬롯**  | **속성**           | **값**                           |
| -------- | --------- | ------------------ | -------------------------------- |
| Solid    | Container | `background-color` | `--color-semantic-bg-default`    |
| Solid    | Icon      | `icon-color`       | `--color-semantic-icon-inverted` |
| Solid    | Container | `text-color`       | `--color-semantic-text-inverted` |
| Outline  | Container | `background-color` | `--color-semantic-bg-default`    |
| Outline  | Icon      | `icon-color`       | `--color-semantic-icon-inverted` |

### **Size**

크기와 타입(Standard, Extended)에 따른 여백 및 치수 사양입니다.

| 상태             | 슬롯      | 속성           | 값        |
| ---------------- | --------- | -------------- | --------- |
| Solid (Standard) | Container | width / height | 44px      |
| Solid (Extended) | Container | height         | 44px      |
| Solid (Extended) | Container | padding        | 12px 16px |
| Solid (Extended) | Container | gap            | 4px       |
| Outline (Small)  | Container | width / height | 44px      |
| Outline (Large)  | Container | width / height | 48px      |
