## Anatomy

![image.png](/images/docs/components/action-button/image-0.png)

1. Container
2. prefix icon(optional)
3. suffix icon(optional)
4. label

## Properties

### Size

![image.png](/images/docs/components/action-button/image-1.png)

인터페이스의 밀도와 계층 구조에 따라 선택할 수 있는 크기(XL,L,M,S,XS)를 제공합니다. 각 각 지정된 높이(Height)와 패딩(Padding) 값을 가집니다.

### Variant

![image.png](/images/docs/components/action-button/image-2.png)

화면 내 시각적 중요도에 따라 Solid(배경 채움), Outline(테두리), Ghost(배경 없음) 를 사용합니다

### State

![image.png](/images/docs/components/action-button/image-3.png)

사용자 상호작용 상태를 나타냅니다. `:nomal` `:hovered` `:focused` `:pressed` `:disabled`를 활용하여 각 상태에 맞는 시각적 피드백을 제공합니다.

### Width(min,max)

![image.png](/images/docs/components/action-button/image-4.png)

내부 텍스트 길이에 따라 버튼 너비가 유동적으로 변하되 레이아웃이 깨지지 않도록 `min-width` 와 `max-width` 속성을 통해 제약 조건을 설정합니다.

## Guidelines

### Hierarchy

![image.png](/images/docs/components/action-button/image-5.png)

한 화면에서 여러 개의 Action Button이 제공될 때, 시각적 위계를 통해 사용자의 주요 행동을 유도해야 합니다.

| 위계   | 추천 Variant | 설명                                                                                                  | 주의사항                                                                                            |
| ------ | ------------ | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| High   | Solid        | 사용자가 수행해야 하는 가장 중요한 핵심 동작에 사용합니다.                                            | 가급적 한 화면의 동일한 맥락 내에서 1개만 배치합니다.                                               |
| Medium | Outline      | 취소, 이전 등 동작을 보조하는 대안 동작에 사용하거나, 강조되지 않아도 될 정보를 제공할 때 사용합니다. | High emphasis 버튼과 함께 인접하게 배치하여 대비를 주거나 시각적 노이즈를 줄이도록 단독 배치합니다. |
| Low    | Ghost        | 부가적인 기능이나 시각적 노이즈가 적어야 하는 옵션 동작에 사용합니다.                                 | 주변 텍스트나 레이아웃과 혼동되지 않도록 여백에 주의합니다.                                         |
