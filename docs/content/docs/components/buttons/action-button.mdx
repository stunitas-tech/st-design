## Anatomy

![Anatomy img](/images/docs/component/action-button/img01.png)

1. Container
2. prefix icon(optional)
3. suffix icon(optional)
4. label

## Properties

### Size

![Size img](/images/docs/component/action-button/img02.png)

인터페이스의 밀도와 계층 구조에 따라 선택할 수 있는 크기(XL,L,M,S,XS)를 제공합니다. 각 각 지정된 높이(Height)와 패딩(Padding) 값을 가집니다.

### Tone

버튼의 성격과 컨텍스트에 맞춰 배경색 및 텍스트 색상 조합을 변경하는 클래스를 제공합니다.

### Layout \*웅

버튼 내부의 텍스트와 아이콘 배치 방식을 결정합니다. 아이콘 좌측 배치, 아이콘 우측 배치, 텍스트 단독, 아이콘 단독 레이아웃 구조를 구성합니다.

### Variant

![Variant img](/images/docs/component/action-button/img03.png)

화면 내 시각적 중요도에 따라 Solid(배경 채움), Outline(테두리), Ghost(배경 없음) 를 사용합니다

### State

![State img](/images/docs/component/action-button/img04.png)

사용자 상호작용 상태를 나타냅니다. `:nomal`,`:hovered`, `:focused`, `:pressed`, `:disabled`를 활용하여 각 상태에 맞는 시각적 피드백을 제공합니다.

### Width(min,max)

![Width img](/images/docs/component/action-button/img05.png)

내부 텍스트 길이에 따라 버튼 너비가 유동적으로 변하되 레이아웃이 깨지지 않도록 `min-width`와 `max-width` 속성을 통해 제약 조건을 설정합니다.

## Guidelines

### Hierarchy

한 화면에서 여러 개의 Action Button이 제공될 때, 시각적 위계를 통해 사용자의 주요 행동을 유도해야 합니다.

| 위계   | 추천 Variant | 설명                                                                                                  | 주의사항                                                                                            |
| ------ | ------------ | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| High   | Solid        | 사용자가 수행해야 하는 가장 중요한 핵심 동작에 사용합니다.                                            | 가급적 한 화면의 동일한 맥락 내에서 1개만 배치합니다.                                               |
| Medium | Outline      | 취소, 이전 등 동작을 보조하는 대안 동작에 사용하거나, 강조되지 않아도 될 정보를 제공할 때 사용합니다. | High emphasis 버튼과 함께 인접하게 배치하여 대비를 주거나 시각적 노이즈를 줄이도록 단독 배치합니다. |
| Low    | Ghost        | 부가적인 기능이나 시각적 노이즈가 적어야 하는 옵션 동작에 사용합니다.                                 | 주변 텍스트나 레이아웃과 혼동되지 않도록 여백에 주의합니다.                                         |

### Usage

#### 명확한 레이블 작성 규칙

| Type  | Description                                                                                   |
| ----- | --------------------------------------------------------------------------------------------- |
| Do    | "저장", "삭제", "전송"과 같이 간결하고 명확한 동사형 명사를 사용합니다.                       |
| Don't | "여기를 클릭하세요", "확인해보기"와 같이 모호하거나 불필요하게 긴 문장형 텍스트는 지양합니다. |

## Specification

### base \*웅

| 상태     | 슬롯      | 속성              | 값            |
| -------- | --------- | ----------------- | ------------- |
| Default  | Container | `display`         | `inline-flex` |
| Default  | Container | `align-items`     | `center`      |
| Default  | Container | `justify-content` | `center`      |
| Default  | Container | `box-sizing`      | `border-box`  |
| Disabled | Container | `cursor`          | `not-allowed` |
| Disabled | Container | `opacity`         | `0.4`         |

### Variant

버튼의 시각적 형태를 결정하는 스타일 속성으로, HTML 클래스(예: `.btn-solid`, `.btn-outline`)를 통해 제어합니다.

| 상태            | 슬롯      | 속성               | 값                                          |
| --------------- | --------- | ------------------ | ------------------------------------------- |
| Solid           | Container | `background-color` | `--color-semantic-bg-default`               |
| Solid           | Container | `text-color`       | `--color-semantic-text-default`             |
| Outline-primary | Container | `border`           | `1px solid --color-semantic-stroke-default` |
| Outline-primary | Container | `background-color` | `--color-semantic-bg-default`               |
| Outline-assist  | Container | `border`           | `1px solid --color-semantic-stroke-accent`  |
| Outline-assist  | Container | `background-color` | `--color-semantic-bg-default`               |
| Ghost-primary   | Container | `background-color` | `transparent`                               |
| Ghost-primary   | Container | `text-color`       | `--color-semantic-text-default`             |
| Ghost-assist    | Container | `background-color` | `--color-action-ghost-hover-bg`             |
| Ghost-assist    | Container | `text-color`       | `--color-semantic-text-subtle`              |

### Size

버튼의 크기를 결정하는 스타일 속성으로, 높이와 내부 여백을 통해 크기를 규격화합니다.

| 상태   | 슬롯      | 속성      | 값       |
| ------ | --------- | --------- | -------- |
| XSmall | Container | `height`  | `28px`   |
| XSmall | Container | `padding` | `0 8px`  |
| Small  | Container | `height`  | `32px`   |
| Small  | Container | `padding` | `0 12px` |
| Medium | Container | `height`  | `40px`   |
| Medium | Container | `padding` | `0 12px` |
| Large  | Container | `height`  | `44px`   |
| Large  | Container | `padding` | `0 16px` |
| XLarge | Container | `height`  | `48px`   |
| XLarge | Container | `padding` | `0 16px` |
