## Properties

### Direction

Navigation Button은 이동 방향에 따라 두 가지 Direction `previous` `next` 을 가집니다.

![image.png](/images/docs/components/navigation/navigation-button/image-1.png)

### Size

내비게이션 버튼은 다양한 사용 환경과 계층 구조에 맞추어 3가지 크기(Large, Medium, Small) 클래스를 제공합니다.

- Large: 주요 콘텐츠 이동에 사용합니다.
- Medium/Small: 좁은 영역이나 보조적인 콘텐츠 이동에 사용합니다.

![image.png](/images/docs/components/navigation/navigation-button/image-2.png)

### Variants

Navigation Button은 기본적으로 원형 버튼 형태를 사용합니다.

![image.png](/images/docs/components/navigation/navigation-button/image-3.png)

<Callout title="Pagination이나 Step Navigation 안에서 사용되는 사각형/그룹형 버튼은 Navigation Button의 독립 Variant로 추가하지 않습니다. 해당 형태는 상위 컴포넌트 또는 패턴의 조합 스타일로 관리합니다." type="warn">

</Callout>

### State

사용자 상호작용 상태를 나타냅니다. `:nomal` `:hovered` `:focused` `:pressed` `:disabled`를 활용하여 각 상태에 맞는 시각적 피드백을 제공합니다. `:disabled` 상태에서는 상호작용이 불가능합니다.

![image.png](/images/docs/components/navigation/navigation-button/image-4.png)

## Guidelines

### Behavior

버튼을 클릭하면 이전 또는 다음 콘텐츠로 이동되며, 반복 구조에서는 loop 여부에 따라 동작이 달라질 수 있습니다.

![image.png](/images/docs/components/navigation/navigation-button/image-5.png)

### Navigation button의 활용

Navigation Button은 단독으로 사용하기보다 콘텐츠 이동 패턴 안에서 함께 사용합니다.

- Pagination의 이전/다음 이동
- Step Navigation의 순차 이동
- Carousel, Slider의 콘텐츠 이동
